# Summarly plugins for Claude

The marketplace for [Summarly](https://summarly.com)'s Claude plugin.

**Add it in Claude:** Customize → Plugins → Add → Add marketplace, and enter `summarly/claude-plugin`. Then install **Summarly**.

The plugin connects Claude to your Summarly books (read-only) and adds workflows for reviewing a month, chasing missing receipts, your cash position and supplier spend. See [plugins/summarly](plugins/summarly) and [summarly.com/mcp](https://summarly.com/mcp).

This repository is published from Summarly's main codebase, where the plugin lives next to the server it talks to; changes made here directly will be overwritten.
